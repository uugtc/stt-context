# STT Context 設計

承認: 2026-09-17。チャットの設計案を基に、ユーザーの指定で Swift を Electron + TypeScript に変更。

## 目的と対象
Mac でオンライン会議を録音、または音声ファイルを取り込み、資料・専門用語・自由文の背景情報を音声認識に渡す。会議終了後に話者別の文字起こしと根拠付き要約を作る。個人利用から始め、一般的に分かりやすい操作を目指す。macOS 15 以降を初版対象とする。

## 操作
テーマは任意。テーマを選ぶ→今回の背景情報を追加→録音開始→停止→自動処理→要約・文字起こしを確認。音声の取り込みも同じ処理を使う。画面は会議一覧、会議詳細（要約・文字起こし・背景）、テーマ管理、設定。録音中は経過時間とマイク／システム音声のメーターを表示。システム音声はPC全体が対象となり得ることを明示し、特定アプリ限定を保証しない。

## 背景情報
テーマと会議それぞれに、自由文、PDF/TXT/Markdown資料、単語＋任意の読み方を登録。使用例入力は不要。PDFにテキストがなければOCR未対応と知らせる。資料はコピーを保存し出典と抽出結果を保持。優先度は会議の手動指定→テーマの手動指定→資料抽出。推定した読みは確定しない。認識用の文脈は長さ制限内に整理し、手動登録を先に採用。資料由来の用語は編集・除外できる。処理時の背景情報を保存する。

## 処理
話者識別と文脈付き認識を分離。第一段階は gpt-4o-transcribe-diarize の diarized_json（speaker/start/end）、第二段階は該当音声を文脈付きで認識。初期モデルは利用可能性の確認を優先し、gpt-4o-transcribe を利用可能な既定候補、gpt-transcribe も設定可能にする。API呼び出しはmain側のみ。話者区間を細切れにしすぎず、無音・短発言・境界・同時発言・未割当区間を扱う。モデルが返す誤った区間を検証する。長音声は上限内へ分割。分割をまたぐ話者一致は確実でない場合に別IDを保ち、手動統合できる。新しい区間の識別は原文の文字列だけに依存しない。

要約は概要・論点・決定事項・次の行動（担当者/期限）・未決事項。根拠のsegment IDを保存する。資料にだけある内容を発言として扱わず、担当者/期限は不明なら未指定。本文修正後は要約を古い状態として示す。再認識は候補として保存し、手動編集を自動上書きしない。

## 技術と構造
Electron + React + TypeScript + Vite。ローカルDB、音声・資料ファイル。独自サーバーなし。APIキーはElectron safeStorage（macOSキーチェーンに基づく暗号化）で保護し平文保存しない。rendererはNode非公開、contextIsolationとsandbox有効、型付き限定IPC。録音はMediaRecorderでマイク/システム別トラックとミックスを保存。ネイティブビルド依存は極力避ける。音声変換はFFmpegを使用し、導入済みバイナリまたは設定パスから起動（シェルを経由しない）。

各機能をUI、録音、永続化、背景整理、音声変換、APIアダプター、ジョブ処理へ分離。状態は準備/録音/待機/処理中/完了/失敗。途中結果・モデル/設定/文脈のスナップショットを残し再試行。異常終了後の録音ファイルを保持して復旧。生の文字起こしと編集を分ける。本文/話者の編集、区間再生、再認識候補、Markdown/TXT書出し、音声を含む削除を提供。

## 初版外
フォルダ監視、クラウド資料連携、OCR、Word/PowerPoint、リアルタイム文字起こし、チーム共有、会議bot、Windows対応、署名済み一般配布。

## 品質と検証
背景なし/単語のみ/資料由来で同一音声を比較し、用語正解と過剰挿入、否定/数字の保持を評価。実API・実会議はキーと録音権限/ユーザーのサンプルが必要。UI・型検査・ローカル永続化・音声変換・ジョブ再開・API境界は自動テスト可能。ネット切断でも録音継続。権限拒否・入力断・異常終了・長音声・分割境界を検証する。未検証の実録音/認識精度を検証済みと表示しない。

## 判断記録
1. Electron採用: 普段のTypeScript/Reactを使い、フルXcode必須を避ける。容量/メモリ増と録音のOS依存は受容。
2. ローカル保存/API直結: 個人利用で独自サーバーとアカウント管理を省く。音声と抽出文章はAPIへ送られるため初期画面に明示。
3. 二段認識: 話者識別モデルのprompt非対応を補う。追加処理時間とAPI利用を受容し、最初に品質検証する。
4. 変更履歴と文脈snapshot: 再認識や資料変更から編集結果を保護する。
